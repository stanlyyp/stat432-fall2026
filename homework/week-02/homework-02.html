Both metrics evaluate how well a model fits the data while penalizing it for complexity, helping you select a model that balances goodness-of-fit and parsimony (simplicity) to prevent overfitting.

Question 5: Validation and final test data

1. Misuse Identification and Selection Bias

First misused step: Step 2 is the first misuse. Although regression coefficients were estimated using only the training data, the final test data were used to select the predictor count .

Why the minimum test MSE is overly optimistic: The test set contains random sampling variability. Selecting the candidate with the minimum test MSE favors a model that profited from "lucky" random fluctuations on that specific test sample, leading to an overly optimistic (underestimated) prediction error.

2. Correct 5-Fold Cross-Validation Workflow

Reserve Final Test Data: Fully lock away rows 371 through 442 without inspecting their features or responses.

5-Fold Cross-Validation on Training Data: Divide rows 1 through 370 into 5 equal folds. For each predictor count , fit on 4 folds, validate on the remaining fold, and compute the average validation MSE across all 5 iterations.

Select Predictor Count: Choose the  that achieves the lowest average cross-validation MSE.

Refit Model: Refit the model with  predictors using all 370 training observations.

Final Evaluation: Evaluate the refitted model once and only once on the locked test data (rows 371–442) to obtain an unbiased estimate of prediction error.

(Note: Any data-dependent preprocessing must also be estimated within each training fold).

3. Remediation After Examining Test Data

Transparent Reporting: The analysis can only be reported as exploratory, explicitly acknowledging that the test set was used for hyperparameter selection. The reported minimum cannot serve as an untouched final evaluation.

Required Additional Data: A new, independent test dataset or genuinely new future observations are required to conduct an unbiased final evaluation.
